# just for fun

Overview:
This is a simple calculator application built using Python and the CustomTkinter library, which provides modern-looking GUI components with customizable themes.

Features:

-Basic arithmetic operations (addition, subtraction, multiplication, division)
-Clear button to reset the calculation
-Error handling for invalid expressions
-Dark mode appearance with blue theme
-Responsive grid layout for buttons
-Large, readable display

Requirements:

-Python 3.x
-CustomTkinter library

Code Structure:
-The calculator class contains all the application logic
-__init__ method sets up the main window and display
-layout method creates the button grid
-on_button_click handles button press events
-calculate evaluates the expression and displays the result
